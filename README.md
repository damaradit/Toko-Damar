# Toko Damar — Website Interaktif

Website profil toko responsif dengan tema putih, biru, hitam, dan abu-abu.

Fitur:
- Animasi masuk saat scroll, ilustrasi toko mengambang, dan progress bar scroll
- Navigasi responsif untuk HP
- Pencarian produk dan filter kategori interaktif
- Link WhatsApp dan Google Maps
- Efek hover pada kartu
- Menghormati preferensi reduced motion

Cara melihat: buka `index.html` menggunakan browser.

Deploy GitHub Pages:
1. Upload `index.html` dan `README.md` ke root repository GitHub.
2. Masuk ke Settings → Pages.
3. Pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu simpan.
